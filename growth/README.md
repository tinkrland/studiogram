# growth

tin.computer-style marketing project for studiogram, run by the owner's
superagent. plain files with git history. this folder is compose-only:
nothing here ships, posts, or changes any live surface without the owner's
explicit approval. drafts arrive as commits for review, never as actions.

contents:

- growth-wiki/positioning.md: what studiogram is against, and for whom
- growth-wiki/icp.md: buyer segments, in order of readiness
- growth-wiki/buyer-questions.md: the buyer questions to own
- reports/deep-dive-2026-10-17.md: the ai-flag research pass, with sources
- content/: answer-page drafts composed from that research
- plan/2026-Q4.md: the first plan, sized to a pre-launch studio

house rules: prose lowercase, no emojis, no em dashes, exact case preserved
in identifiers and urls. every outside claim carries its source. claims
not yet verified against the primary policy pages are marked "needs full
read before publishing".
